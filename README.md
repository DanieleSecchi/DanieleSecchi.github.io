# Dannimapping Twin — informazioni pubbliche

Pagine informative dell’applicazione personale Dannimapping Twin.

- `index.html`: presentazione e finalità.
- `privacy.html`: accesso e utilizzo dei dati.
- `terms.html`: condizioni d’uso.
- `style.css`: stile condiviso.

Questo repository contiene soltanto le pagine informative. Non include archivi
personali, credenziali o codice di elaborazione.

## Pubblicazione

In **Settings → Pages**, scegliere **Deploy from a branch**, ramo **pages**,
cartella **/ (root)**, quindi **Save**.

Gli indirizzi previsti dopo l’attivazione sono:

- https://danielesecchi.github.io/
- https://danielesecchi.github.io/privacy.html
- https://danielesecchi.github.io/terms.html

L’attivazione e la raggiungibilità degli indirizzi devono essere verificate.
Queste pagine non attivano la sincronizzazione del Twin.
